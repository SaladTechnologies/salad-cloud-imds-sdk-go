# ReallocatePrototype

Represents a request to reallocate the current container instance to another SaladCloud node.

**Properties**

| Name   | Type   | Required | Description                                                                                                                                                  |
| :----- | :----- | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reason | string | ✅       | The reason for reallocating the current container instance. This value is reported to SaladCloud support for quality assurance purposes of SaladCloud nodes. |
